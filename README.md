I write **Rust** for low-level tools, protection and infrastructure, and use **Python** for CTF / exploit work.

- 🛡️ Binary protection & anti-reversing

- 🌐 Practical networking tools (proxy, Workers)
- 🚩 CTF (mainly Reverse / PWN) & red-team utilities
